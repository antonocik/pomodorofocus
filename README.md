# PomodoroFocus

Timer produktivitas menggunakan teknik Pomodoro. Pengaturan durasi kustom, notifikasi suara, dan tampilan progres.

## Fitur
- Timer Pomodoro (25 menit by default)
- Pengaturan durasi fokus & istirahat (5-10 menit)
- Tombol Play/Pause, Reset
- Notifikasi suara saat sesi selesai
- Ringkasan sesi harian (berapa pomodoro yang selesai)
- Penyimpanan durasi terakhir di LocalStorage
- Responsif

## Menjalankan
Buka `index.html` di browser, atau:
```bash
python3 -m http.server 8080
```
